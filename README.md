# QuoteKit IL

Free Hebrew/English quote and VAT calculator for Israeli freelancers, plus a quote template (CSV) you can download.

- This is a **quote / pricing worksheet, not a tax invoice (חשבונית מס)** and not legal or tax advice. VAT rate is editable; check the current rate.
- The template is pay-what-you-feel (suggested $1) on trust, via PayPal.me. No account, no tracking, no backend.
