# QuoteKit IL

הצעת מחיר מסודרת ללקוח, עם מע"מ מחושב, תוך דקה. מחשבון חינמי בעברית ובאנגלית לפרילנסרים בישראל (עוסק מורשה ועוסק פטור), הדפסה ל-PDF, ותבנית CSV להורדה.

Free Hebrew/English quote and VAT calculator for Israeli freelancers, plus a downloadable CSV template.

- This is a **quote / pricing worksheet, not a tax invoice (חשבונית מס)** and not legal or tax advice. The VAT rate is editable; check the current rate.
- The template is open to download; support is pay-what-you-feel (suggested $1) via PayPal.me.
- No account, no backend, no third-party tracking. Usage events (page view, calculator used, clicks) are stored only in the visitor's own browser (localStorage) and are not sent anywhere.
